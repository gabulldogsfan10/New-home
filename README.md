# 2414 19th Ave — New Home Tracker

A shared list for Joshua & April for the house at 2414 19th Ave, Columbus, GA 31901 (closing Dec 3, 2026).

Three tabs:

- **To buy** — things the house needs, grouped by room. The circle moves an item from *Still need* → *Ordered* → *Got it*. Tap an item to set a price, link, who's buying it, and notes. The header totals what's left in the budget.
- **Staying** — the 24 items the seller checked on the Fixtures Checklist (GAR F301, signed 10/21/2026). Use it at the final walk-through.
- **Closing** — deadlines and to-dos from the Purchase and Sale Agreement (earnest money, 10-day due diligence, termite letter, utilities, homestead exemption).

## Files

- `app.html` — the app (HTML/CSS/JS in one file). This is the version published as a shared Claude artifact, where both of you see the same list.
- `index.html` — the same app as a complete web page, built by `node scripts/build.mjs`. Open it in a browser or host it with GitHub Pages. In this mode the list is saved on that device only.

## Where the starter data came from

- Seller's Property Disclosure Statement (F301): fixtures staying, built 1933, tankless water heater (age unknown), HVAC serviced 10/22/2026, roof ~8–9 years old.
- Purchase and Sale Agreement (F201): $245,000 price, $10,000 seller contribution, $2,500 earnest money within 3 days, 10-day due diligence, closing 12/03/2026, termite-letter stipulation.

Dates marked ≈ are counted from the Binding Agreement Date, so check them with your agent.
